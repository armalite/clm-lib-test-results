# HB-06 · Policy FAQ
version: 7 · status: current · effective: 2026-01-15

§1 Current home-office equipment allowance
Q: What is the current standard home-office equipment allowance? A: 500 EUR, as set in HB-11 §2 (effective 2026-03-01). Group exceptions are listed in HB-09.

§2 Current daily meal allowance
Q: What is the current standard daily meal allowance? A: 54 EUR per day, as set in HB-27 §2 (effective 2026-05-01). Group exceptions are listed in HB-33.

§3 Current annual training budget
Q: What is the current standard annual training budget? A: 1150 EUR per year, as set in HB-18 §2 (effective 2026-02-01). Group exceptions are listed in HB-26.

§4 Current nightly lodging limit
Q: What is the current standard nightly lodging limit? A: 150 EUR per night, as set in HB-22 §2 (effective 2026-02-01). Group exceptions are listed in HB-03.

§5 Current mileage rate
Q: What is the current standard mileage rate? A: 34 cents per km, as set in HB-29 §2 (effective 2026-06-01). Group exceptions are listed in HB-39.

§6 Current monthly mobile allowance
Q: What is the current standard monthly mobile allowance? A: 40 EUR per month, as set in HB-37 §2 (effective 2026-06-01). Group exceptions are listed in HB-25.

§7 Current purchase approval threshold
Q: What is the current standard purchase approval threshold? A: 2500 EUR, as set in HB-08 §2 (effective 2026-02-01). Group exceptions are listed in HB-01.

§8 Current relocation lump sum
Q: What is the current standard relocation lump sum? A: 3500 EUR, as set in HB-35 §2 (effective 2026-06-01). Group exceptions are listed in HB-10.
