# HB-02 · Policy FAQ
version: 7 · status: current · effective: 2026-01-15

§1 Current mileage rate
Q: What is the current standard mileage rate? A: 32 cents per km, as set in HB-24 §2 (effective 2026-04-01). Group exceptions are listed in HB-10.

§2 Current relocation lump sum
Q: What is the current standard relocation lump sum? A: 2500 EUR, as set in HB-23 §2 (effective 2026-02-01). Group exceptions are listed in HB-18.

§3 Current home-office equipment allowance
Q: What is the current standard home-office equipment allowance? A: 375 EUR, as set in HB-39 §2 (effective 2026-06-01). Group exceptions are listed in HB-08.

§4 Current daily meal allowance
Q: What is the current standard daily meal allowance? A: 60 EUR per day, as set in HB-33 §2 (effective 2026-02-01). Group exceptions are listed in HB-35.

§5 Current annual training budget
Q: What is the current standard annual training budget? A: 1250 EUR per year, as set in HB-32 §2 (effective 2026-02-01). Group exceptions are listed in HB-30.

§6 Current purchase approval threshold
Q: What is the current standard purchase approval threshold? A: 4000 EUR, as set in HB-15 §2 (effective 2026-05-01). Group exceptions are listed in HB-22.

§7 Current monthly mobile allowance
Q: What is the current standard monthly mobile allowance? A: 32 EUR per month, as set in HB-04 §2 (effective 2026-05-01). Group exceptions are listed in HB-29.

§8 Current nightly lodging limit
Q: What is the current standard nightly lodging limit? A: 210 EUR per night, as set in HB-21 §2 (effective 2026-06-01). Group exceptions are listed in HB-06.
