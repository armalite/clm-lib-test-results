# HB-04 · Policy FAQ
version: 7 · status: current · effective: 2026-01-15

§1 Current annual training budget
Q: What is the current standard annual training budget? A: 900 EUR per year, as set in HB-07 §2 (effective 2026-03-01). Group exceptions are listed in HB-09.

§2 Current relocation lump sum
Q: What is the current standard relocation lump sum? A: 3000 EUR, as set in HB-08 §2 (effective 2026-06-01). Group exceptions are listed in HB-39.

§3 Current mileage rate
Q: What is the current standard mileage rate? A: 32 cents per km, as set in HB-16 §2 (effective 2026-06-01). Group exceptions are listed in HB-17.

§4 Current home-office equipment allowance
Q: What is the current standard home-office equipment allowance? A: 500 EUR, as set in HB-34 §2 (effective 2026-04-01). Group exceptions are listed in HB-38.

§5 Current daily meal allowance
Q: What is the current standard daily meal allowance? A: 56 EUR per day, as set in HB-01 §2 (effective 2026-05-01). Group exceptions are listed in HB-32.

§6 Current nightly lodging limit
Q: What is the current standard nightly lodging limit? A: 155 EUR per night, as set in HB-40 §2 (effective 2026-03-01). Group exceptions are listed in HB-11.

§7 Current monthly mobile allowance
Q: What is the current standard monthly mobile allowance? A: 28 EUR per month, as set in HB-13 §2 (effective 2026-05-01). Group exceptions are listed in HB-31.

§8 Current purchase approval threshold
Q: What is the current standard purchase approval threshold? A: 4000 EUR, as set in HB-10 §2 (effective 2026-05-01). Group exceptions are listed in HB-18.
